# Security policy

## Supported versions

The project is in development. Until the first stable release, security fixes target the `main` branch.

## Reporting a vulnerability

Email [Serhii Andriichuk](mailto:andriichuk29@gmail.com) with the subject `LiqPay PHP SDK security report`. Include the affected revision or version, a description of the issue, its impact and a minimal reproduction using test data.

Please report vulnerabilities privately before opening public issues or pull requests. Do not include real merchant credentials, card details or customer data.

The SDK's signing code, callback verification and HTTP handling are in scope. Account configuration and issues in LiqPay itself should also be reported through LiqPay's official support channels.
